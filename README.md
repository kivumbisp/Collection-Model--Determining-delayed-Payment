# Collection-Model--Determining-delayed-Payment
The Machine Learning Collection Model – Determining Customer Payment Periods &Comsumption Trends, Mid-Month Collection Updated Reports analyzes historical billing and payment behavior. 
The Machine Learning Model developed to predict likely defaulters is now in use, and was applied upon the closure of Cycle 8. Out of a total of 30,2169 customers processed in Cycle 8, the model identified 4,953 customers as exceptions (predicted likely defaulters). This represents approximately  70.49% of the total customer base for the cycle, highlighting the scale of default risk flagged by the predictive model.
